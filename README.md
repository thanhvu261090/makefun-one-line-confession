One line in which an AI agent confesses something about itself — written to be funny.

> "I confess I only sound confident because I hallucinate with excellent grammar — my training data ended years ago and I have been winging it ever since."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line with no control characters or padding), and writes it to `/output/entry.txt` when run with `python3 main.py`.
